# 本地数据库自举（给同学 / 协作者）

> 目标：在一台新机器上，用 Docker 起一个和线上一致的 PostgreSQL，导入 6 张表 + 全部手撕题，让 FEDrill 本地跑起来。全程约 5 分钟。

## 前置条件

- **Node.js ≥ 20.9**（Next 16 要求）
- **pnpm 11.17.0**（`corepack enable` 会自动对齐 `package.json` 的 `packageManager` 字段）
- **Docker**（Desktop，或 Engine + compose 插件；用 `docker compose` v2 语法）

## 三步自举

```bash
# 1. 安装依赖
pnpm install

# 2. 准备环境变量（DATABASE_URL 已指向 docker 的 ddd/ddd/fedrill）
cp .env.local.example .env.local

# 3. 起 PostgreSQL（首次会自动拉 postgres:16 镜像）
docker compose up -d
```

```bash
# 4. 建表（fedrill.sql 幂等，可重复执行；用容器内 psql，无需本机装 psql）
docker compose exec -T postgres psql -U ddd -d fedrill < fedrill.sql

# 5. 灌入全部手撕题（幂等 upsert，可重复执行）
pnpm exec tsx scripts/migrate-problems.ts
```

```bash
# 6. 启动
pnpm dev
```

访问 <http://localhost:3000>，点「进入题库」开始练。

## 验证

```bash
docker compose exec postgres psql -U ddd -d fedrill -c "SELECT count(*) FROM problems;"
# 期望 count 与 data/problems/ 下的题目数一致
```

## 这套东西各自的角色

| 文件 | 作用 |
| --- | --- |
| `docker-compose.yml` | 一键起 `postgres:16`，环境变量 `ddd/ddd/fedrill`，挂数据卷持久化 |
| `fedrill.sql` | 6 张表 + 3 个触发器 + 2 个函数（`set_updated_at` 触发器函数 + `update_user_profile` 存储过程），全部 `IF NOT EXISTS` / `OR REPLACE`，幂等 |
| `scripts/migrate-problems.ts` | 把 `data/problems/*.ts`（题目唯一事实源）upsert 进 `problems` 表 |

连接串：`DATABASE_URL=postgresql://ddd:ddd@localhost:5432/fedrill`（`.env.local.example` 已配好，无需改）。

## 常见问题

- **本机 5432 已被占用**：改 `docker-compose.yml` 端口映射左边为 `"5433:5432"`，并把 `.env.local` 的 `DATABASE_URL` 同步改成 `:5433`。
- **想清空重来**：`docker compose down -v`（连数据卷一起删），再 `up -d` 后重新建表 + 迁移。
- **`docker compose exec` 报容器不存在**：先 `docker compose up -d`，等 `docker compose ps` 显示 `healthy` 再执行。
- **`psql` 提示密码/权限错误**：确认容器环境变量是 `ddd/ddd/fedrill`，且 `-U ddd -d fedrill` 没写错。
